# 阶段输出合同（Output Contract）

> 层级：L0 CORE
> 版本：v1.0
> 目的：固定短格式，降低输出 Token，避免每轮复述规范

## 1. 默认短格式（所有阶段）

```text
【阶段】<phase_id> | <阶段名>
【结论】<3-8 行要点>
【证据】<文件路径 / 命令 / 规则 ID>
【待确认】
- <item>   （无则写：无）
【下一步】请回复：确认 / 补充… / 停止
【状态】进行中 | 已阻塞 | 等待确认 | 已完成
```

## 2. 阶段类型与必出字段

| 阶段类型 | 必出字段 |
|----------|----------|
| 分析/范围 | 结论、证据路径、待确认、下一步 |
| 设计 | 方案要点、影响文件、风险、待确认 |
| 编码 | 代码/路径、关键逻辑 5 行内、自检规则 ID |
| 校验 | 命令、通过/失败、失败项 |
| Review | 规则 ID 列表、P0～P3 问题表 |
| 交付 | 变更摘要、证据索引（不重复贴全文） |

## 3. 使用要求

- 每轮只输出本阶段短合同，不输出旧 8 段大模板。
- 证据只给路径/命令/规则 ID，不贴全文。
- 待确认事项必须逐项列出，不得隐式带过。
