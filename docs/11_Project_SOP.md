# 11 项目 SOP

## 11.1 概述

本文件只保留项目主流程总纲。具体执行规则以 `docs/offline-first-development.md` 和对应专项规范为准。

## 11.2 项目主流程

项目开发只使用两类主流程：

1. `requirement_development`：根据需求文件分析并开发目标表存储过程及临时表。
2. `schema_change`：根据 Mapping Excel 最近变更同步 MD、DD 和数据字典。

流程由用户命令语义自动路由。语义无法唯一判断时，必须停止修改并请求确认。

## 11.3 执行顺序

需求开发主线为：

1. 需求分析与确认
2. 数据分析
3. 数据字典确认
4. Mapping 设计
5. SQL 设计
6. 存储过程设计
7. ETL 设计
8. Explain 分析
9. Code Review
10. 测试
11. 上线

表结构变更主线为：

1. Mapping Excel 最近变更分析
2. 关联 MD/DD/数据字典扫描
3. 修改范围用户确认
4. 资产修改
5. 一致性审核
6. 完整校验
7. 用户确认

## 11.4 约束

- 任何阶段都不能跳过。
- 不确定内容必须标记为 `【待确认】` 或 `unresolved`。
- 需求、字典、Mapping、SQL、存储过程之间必须保持可追溯一致。
- 需要展开细则时，直接跳转专项文档，不在本文件重复维护。
