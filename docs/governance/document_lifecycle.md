# 文档与资产生命周期

> 层级：L1 流程规则
> 版本：v1.0

| 状态 | 含义 | 处理要求 |
|------|------|----------|
| ACTIVE | 当前有效且可执行 | 作为当前流程或业务事实的引用源 |
| SUPERSEDED | 已被明确的新版本替代 | 保留替代关系，不再作为默认事实源 |
| ARCHIVED | 仅保留审计或历史用途 | 不参与默认执行或决策 |

替代或归档必须记录原因、替代对象和 Change ID。业务事实变更需同步维护对应需求、记忆卡片、Mapping、DDL、实现及验证关系；没有明确替代关系时禁止批量删除历史材料。
