# 治理 RACI

> 层级：L1 流程规则
> 版本：v1.0

| 活动 | 业务负责人 | 用户/审批人 | AI 执行者 | Reviewer |
|------|------------|-------------|-----------|----------|
| 业务规则确认 | A/R | A | C | C |
| Change ID、范围与排除项 | C | A | R | C |
| Mapping 与 DDL 事实确认 | A/R | A | C | C |
| SQL、过程、ETL 或治理规则实现 | C | A | R | C |
| QA/QB 自动校验 | I | I | R | C |
| QC 业务审查 | A | A | C | R |
| 发布验收 | C | A | R | C |
| Commit / Push 授权 | I | A | R | I |
| Lesson 与规则改进 | C | A | R | C |

R=执行，A=最终负责/批准，C=协商，I=知会。AI 不具备业务口径、发布、提交或推送的自主批准权。
