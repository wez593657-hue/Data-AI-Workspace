# 审批治理

> 层级：L1 流程规则
> 版本：v1.0

审批分为四类，不能互相替代：

| 审批 | 触发条件 | 授权范围 |
|------|----------|----------|
| 范围确认 | 方案与 Manifest 完成 | 允许在白名单内实施 |
| 业务确认 | 业务口径、字段、Mapping 或边界已明确 | 允许按确认事实开发 |
| 用户验收 | QA/QB/QC 与 Review 结论齐备 | 认可当前交付结论 |
| Commit / Push 授权 | 用户明确下达命令且门禁通过 | 分别允许提交、推送 |

正式结果只能为 `APPROVED` 或 `REJECTED`，并写入任务证据或 Change Register。无法确认的事项必须为 `【待确认】` 或 `unresolved`，不得使用推测性结论替代审批。
