# 到期承接过程全面重新核验报告

日期：2026-08-01
环境：本地 Oracle 11.2.0.1（ORCL），SCOTT schema（测试隔离规范）
范围：PRC_ADS_CUST_DEADLINE_RMND_DTL / PRC_ADS_CUST_DEADLINE_RMND_STATIS
依据：requirements/到期承接规则记忆卡片.md（v2.14.0 口径）、dws到ads映射.md

## 1. 验证方法

在 SCOTT 测试环境构造 9 个探针客户（C10~C18），覆盖：

| 客户 | 探针场景 |
|---|---|
| C10 | 同月 3 笔到期 + 30 天窗口内多笔购买 + 保险购买 + 周末/端午购买 |
| C11 | 下一期到期日-1 窗口 + 窗口边界购买（07-03 计入 / 07-05 不计） |
| C12 | 跨月购买归属原周期（口径26）+ 未来营销记录（接触状态探针） |
| C13 | 月/季/年三切片一致性（4/15、6/15、9/15、12/15 到期） |
| C14 | EXPR_AMT 截止日探针（06-30 与 07-10 两笔到期） |
| C15 | 空值：金额 NULL、到期日 NULL、客户名/管户缺失、PREV-AUM 快照缺失 |
| C16 | 异常值：负金额、零金额、重复账户 ID |
| C17 | 边界日期：月首 06-01、月末 06-30、Q1 末 03-31 |
| C18 | 过滤规则：通知存款（04）、开放理财（1/3）、封闭理财（2） |

执行：
- 连续 30 天跑批（20260601~20260630，每批运行两过程并归档结果）
- 检查日跑批：20260705、20260731、20260930、20261231
- 每天结果归档至 SCOTT 测试表 TEST_RESULT_ARCHIVE / TEST_WINDOW_ARCHIVE

## 2. 执行结果

- 34 次跑批（30 天 + 4 检查日）全部成功，两过程返回码 0，无运行异常
- 日期函数跨月/季/年边界验证通过（上月末=20260531、上季末=20260331、
  上年末=20251231、当月末/季末/年末正确）

## 4. 不符合项（详见 DEFECTS.md，状态待审核）

| 编号 | 缺陷 | 影响 | 建议 |
|---|---|---|---|
| DEFECT-004 | EXPR_AMT 截止用 SYSDATE 而非 V_SYSDAT | 历史回放已到期金额虚高 | 改 `EXPR_DT <= TO_DATE(V_SYSDAT,'YYYYMMDD')` |
| DEFECT-005 | CNTCT_STATE 无 V_SYSDAT 截止 | 未来营销记录计入接触状态 | 判定增加 MKT_TIME <= V_SYSDAT |
| DEFECT-006 | TAKE_AMT/CROSS_CONV 按 STAT_PERD 聚合未区分周期 | 上季/上月切片错配当期购买 | 分组/关联增加周期边界（BGN/END 或 DATA_DATE） |
| DEFECT-007 | DTL 关联 AUM_BAL 缺 DATA_DATE | 明细行重复、金额放大 | ap 关联增加 DATA_DATE=FIRST_EXPR_DT-1 |
| DEFECT-008 | DWS 重复快照/负金额无防御（观察） | 金额按 JOIN 倍数放大、负值计入 | 去重校验/异常告警（待业务确认） |

## 5. 缺陷影响链分析

- DEFECT-004（SYSDATE 截止）在 T+1 当日跑批影响较小，但在补数、历史重跑、
  测试回放场景下，已到期金额与承接率分母系统性虚高。
- DEFECT-006/007 仅在"同一 STAT_PERD 存在多个周期切片"时触发
  （上月+当月、上季+当季同时有数据，本测试由 C17 Q1/Q2 同时到期暴露），
  单月验证无法发现，属于周期切片全量验证的增量发现。
- DEFECT-008 的 DWS 重复快照放大（C10=2 倍、C15 FRST_AUM 翻倍）为测试数据
  构造暴露，对应需求附录 23"防御性校验"待实施项。

## 6. 已通过的规则与结论

窗口计算、购买边界、跨周期归属、过滤规则、空值兜底、月季年基础切片、
日期函数、统计汇总框架均与需求一致。**阻断级不符合项集中在"截止日语义
（SYSDATE vs V_SYSDAT）"与"周期切片间关联键缺失"两类**，建议优先修复
DEFECT-004~007 后重新回放本验证矩阵。
