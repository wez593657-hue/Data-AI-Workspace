## 二、业务概述

面向到期客户，基于明确可解释的业务规则，对在售产品进行"硬过滤 + 评分排序"，输出 Top3 推荐结果。

模型：全量在售产品池 → 硬过滤（F1风险适配/F2产品可售）→ 候选池 → 四维评分（100分制）→ 排序 → Top3。

---

## 三、数据来源与流向

| 来源表 | 别名 | 用途 |
|--------|------|------|
| DWD_PRDKT_INFO | p | 产品主数据（在售状态、收益率、大类、机构） |
| DWD_PRDKT_INFO_DETAIL | d | 产品属性EAV表，`col_code='PRDKT_RISK'` 取产品风险等级（✅-01） |
| DWD_ACCT_FIN | f | 到期客户识别（30天窗口）+ 客户偏好 + 历史购买 |
| DWD_CUST_INDIV_RISK_INVST | r | 客户风险承受等级 |
| DWD_CUST_INDV_INFO | c | 客户名称/管户经理/归属机构补全 |

```
DWD → PRC_ADS_CUST_PRDKT_RCMD（每日跑批，依赖DWD_ACCT_FIN当日快照）
     → ADS_CUST_PRDKT_RCMD（按DATA_DATE快照）→ 客户经理工作台/营销系统
```

## 四、核心规则

### 4.1 硬过滤

| 规则 | 定义 | 处理 |
|------|------|------|
| F1 风险适配 | 产品风险等级 ≤ 客户风险承受等级 | 不满足直接剔除 |
| F2 产品可售 | 在售 + 渠道可售 | 不满足直接剔除（渠道数据源待确认❓-08） |

### 4.2 评分卡（100分制）

| 维度 | 分值 | 规则要点 |
|------|------|----------|
| 收益吸引力 A | 35 | A1前20%→35/A2 20-50%→25/A3 50-80%→15/A4后20%→5/A5样本不足→15 |
| 期限匹配度 B | 30 | B1偏差≤7天→30/B2 8-30天→20/B3 31-90天→10/B4>90天→0；区间命中B5-B8 |
| 风险舒适度 C | 20 | C1同档→20/C2低1档→20/C3低2档→15/C4低3档+→8 |
| 历史偏好 D | 15 | D1频次最高大类→8/D2最多机构→4/D3买过同类→3 |

### 4.3 输出规则

- Top3 默认输出；候选不足3个返回全部；候选为空返回"暂无适配产品"
- 同分排序：期限匹配度 > 收益吸引力 > 历史偏好 > 产品编号升序
- 推荐理由动态拼接（风险适配/期限命中/收益命中/偏好命中）

### 4.4 分段处理（✅-02）

```
段0 基础数据段 → 段1 风险适配段(F1+C分)→TMP_CART_SAFE
→ 段2 期限命中段(B分) → 段3 收益命中段(A分) → 段4 偏好命中段(D分)
→ 段5 汇总输出段(总分+排序+Top3+占位+补全→目标表)
```

每段独立事务 + SYS_PRC_STEP_LOGS，单段失败可单段重跑。
