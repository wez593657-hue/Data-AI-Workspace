## 二、业务概述

面向**全行所有客户**（圈选源 DWD\_CUST\_INDV\_INFO，2026-09-02 确认，替代原到期承接触发范围），对**普通定期存款、智能存款、理财**三类在售产品按"硬过滤 + 四维评分排序"输出 Top3 推荐。

**评分框架（word V1.1 §4）**：各维度百分制得分 × 权重求和。

| 维度      | 权重  | 数据要点                                   |
| ------- | --- | -------------------------------------- |
| 收益吸引力 A | 35% | 同类分组内收益排名五档（100/80/60/30/0），样本不足中性 60  |
| 期限匹配度 B | 30% | 近三年年日均最大产品单点期限作锚点，偏差五档（100/80/60/30/0） |
| 风险舒适度 C | 20% | 同档 100 / 低1-4档 90-60（及格底线）             |
| 历史偏好 D  | 15% | 三因素组合制 D1-D5（100/80/60/30/0），近一年窗口     |

**候选粒度（V1.0.2 §5.0 方案A）**：普通定期存款按"产品 × 存期档"独立候选，同产品多档可并存 Top3；候选源 = DWD\_PRDKT\_INFO\_ZB。

**硬过滤**：F1 风险适配（产品等级 ≤ 客户等级）+ F2 产品可售（在售且渠道可售）。

## 四、核心规则（word V1.0.2）

### 4.1 硬过滤（word §3）

| 规则      | 定义                | 落地状态                                                          |
| ------- | ----------------- | ------------------------------------------------------------- |
| F1 风险适配 | 产品风险等级 ≤ 客户风险承受等级 | ✅ 存款固定 R1 恒满足；无理财测评客户默认 C2 档统一判定（2026-09-02，替代原"存款放行/理财剔除"口径） |
| F2 产品可售 | 在售                | ✅ 渠道可售条件已删除（2026-09-02）                                       |

### 4.2 评分卡（word §5，百分制×权重）

| 维度   | 分档                                                    | 备注                                                                                                                          |
| ---- | ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| A 收益 | 前10%→100 / 10-30%→80 / 30-50%→60 / 50-80%→30 / 后20%→0 | 同类=类型+期限+等级（✅-31）；样本阈值 <10→中性 60（✅-27）；边界左闭右开（✅-16）                                                                         |
| B 期限 | 命中锚点→100 / 偏差≤3月→80 / 3-6月→60 / 6-12月→30 / >12月→0     | 锚点=近三年年日均最大产品单点期限（✅-45）；存期不做三档归并仍按单点月数评分；期限固定到点（✅-18）；值域 D/M/Y 解析（✅-30）；无历史持有 0 分（✅-33）；理财锚点取到期限 NULL 不计入；产品期限缺失中性 60（T-12） |
| C 风险 | 同档 100 / 低1档 90 / 低2档 80 / 低3档 70 / 低4档+ 60           | 档位数值已确认：客户 risk\_lvl 1-5、理财 COL\_VALUE 01-05、存款固定 1（v2.1.0）                                                                 |
| D 偏好 | 三因素全中 100 / 2项含类型 80 / 2项不含 60 / 1项 30 / 无 0          | 类型/机构（存款=9999/自营理财=9999/代销理财=TANO，✅-32）/同类购买，近一年 12 个月滚动（✅-17）                                                              |

### 4.3 输出（word §6）

* Top3；候选不足 3 全出；空候选"暂无适配产品"占位

* 同分排序：期限 > 收益 > 偏好 > 产品编号升序

* 推荐话术 = word V1.1 §7 完整话术模板：等级阈值高≥80/中60-79/低<60，数据不足用专用话术，组装顺序风险→期限→收益→偏好（SP 3.9.3 已对齐）
