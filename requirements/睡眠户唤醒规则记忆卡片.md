## 二、功能概述

### 功能描述

支持用户查看睡眠客户经营概览及客户明细，帮助用户识别睡眠客户、掌握接触进度和唤醒结果，并支撑后续唤醒经营。

| 周期类型 | 说明 | 选择范围 |
|----------|------|----------|
| 月(M) | 默认当月 | 1月～当月 |

## 四、睡眠客户定义规则

### 定义说明

睡眠客户：AUM余额低于100元且近一年无主动动账交易。

### 判定条件

```sql
-- AUM余额条件
NVL(A.AUM_BAL, 0) < 100

-- 主动动账条件
NOT EXISTS (
  SELECT 1
    FROM DWD_TX_ASET T
   WHERE T.CUST_ID = C.CUST_ID
     AND TO_DATE(REPLACE(SUBSTR(T.TX_DATE, 1, 10), '-', ''), 'YYYYMMDD')
         BETWEEN TO_DATE(V_SYSDAT, 'YYYYMMDD') - 365
             AND TO_DATE(V_SYSDAT, 'YYYYMMDD')
     AND t.JIOYCFFS = '0'  -- 主动动账标识(已确认)
)
```

## 五、统计指标

### 指标列表

| 指标 | 说明 | 计算公式 |
|------|------|----------|
| 睡眠客户数 | 当期睡眠客户总数 | COUNT |
| 已接触客户数 | 当月管户经理有过有效电话、面访、企微和短信接触的客户数 | COUNT(CNTCT_STATE='1') |
| 接触率 | 已接触客户数占睡眠客户数的比例 | 已接触客户数 / 睡眠客户数 × 100% |
| 已唤醒客户数 | 当月新增持有定期、理财或保险产品的睡眠客户数（增量对比：唤醒基线余额=0 AND 当日余额>0） | COUNT(WAKE_STATE='1') |
| 唤醒率 | 已唤醒客户数占睡眠客户数的比例 | 已唤醒客户数 / 睡眠客户数 × 100% |

### 接触状态判断规则

| 规则项 | 说明 |
|--------|------|
| 接触类型 | 电话('1')、面访('2')、企微('3')、短信('4') |
| 接触时间 | 当月（从月初到统计日） |
| 接触人员 | 当前管户客户经理 |

### 唤醒状态判断规则

| 规则项 | 说明 |
|--------|------|
| 判断方式 | **增量对比**：唤醒基线产品余额=0 AND 当日产品余额>0 → 新增持有 → 已唤醒 |
| 唤醒基线 | 月首日取上月末(V_PREV_DAY)，非月首日取当月首日(V_CURR_MONTH_BEGIN) |
| 持有产品 | 定期存款(FIXD_DEPO_BAL)、理财(FIN_BAL)、保险(INSUR_BAL) |
| 状态不可逆 | WAKE_STATE='1'一旦设置永不复原（本月内被唤醒后次日赎回仍保持'1'） |
