## 二、业务概述

从 ODS 层保险业务相关表（YBT 保单系统、IBP 交易流水）抽取数据，加工生成 DWD 层保险账户信息表。

**v3.3.0 当前架构：** 使用 `detail` 与 `fee_aggr` CTE 在单条集合化写入中完成成功缴费明细、交易日期预聚合和四键保单级聚合；不再依赖物理临时表。

## 四、关键计算规则

### 4.1 架构流程（v3.3.0）

```
步骤1: 参数校验 + 目标表全量DELETE + 提交
步骤2: detail CTE（成功缴费明细）→ fee_aggr CTE（交易日期聚合）→ 四键GROUP BY → DWD_ACCT_INSUR
```

### 4.2 缴费成功状态过滤（v3.0.0 核心规则）

明细层 JOIN 条件中强制 `ORD_TRAN_STATUS = '2'`，仅缴费成功的交易进入后续处理链路。

```
INNER JOIN YBT_YBT_POLICY_FEE_LIST a
  ON a.plat_policy_serial = c.plat_policy_serial
 AND a.ord_tran_status = '2'    -- 仅缴费成功
```

### 4.3 退保日期/保险结束日期（CANCL_INSUR_DATE）

根据保险期间类型单位（VALID_PER_UNIT）和数值（VALID_PER_NUM）计算：

| VALID_PER_UNIT | 含义 | 计算方式 |
|----------------|------|----------|
| -1 | 永久 | 返回 '9999-12-31' |
| 0 | 保至确定年龄 | 从证件号码（CERT_ID）截取出生日期 + VALID_PER_NUM 年 |
| 12 | 年 | 起保日期 + VALID_PER_NUM 年 |
| 1 | 月 | 起保日期 + VALID_PER_NUM 月 |
| 2 | 日 | 起保日期 + VALID_PER_NUM 天 |

### 4.4 缴费截止日期（PAY_UPTO_DATE）

根据缴费期间类型单位（PAY_PER_UNIT）计算，规则同上，额外：

| PAY_PER_UNIT/PAY_TYPE | 含义 | 计算方式 |
|-----------------------|------|----------|
| PAY_TYPE='0' | 趸交 | 直接取投保日期（ACCEPT_DATE） |
| PAY_PER_UNIT='-1' | 无期限 | NULL |

### 4.5 INSUR_AMT 清零规则（5种场景）

| 优先级 | 场景 | 条件 | INSUR_AMT |
|--------|------|------|-----------|
| 1 | 保单状态无效 | CONT_STATUS NOT IN ('0','1','2') 或 NULL | 0 |
| 2 | 未生效 | CONT_STATUS = '0' | 0 |
| 3 | 失效 | CONT_STATUS = '2' | 0 |
| 4 | 趸交满一年 | PAY_TYPE='0' AND V_DATA_DATE >= ADD_MONTHS(ACCEPT_DATE, 12) | 0 |
| 5 | 期缴缴满 | PAY_TYPE='1' AND V_DATA_DATE >= 总期数×周期 | 0 |
| 6 | 宽限期过60天 | PAY_TYPE='1' AND V_DATA_DATE > 最近续期日期+1周期+60天 | 0 |
| 7 | 正常 | 以上均不满足 | 新单保费 + 续期累计 |

### 4.6 证件号码处理

- 18位：`SUBSTR(CERT_ID, 7, 8)` 截取出生日期 → `YYYYMMDD`
- 15位：`'19' || SUBSTR(CERT_ID, 7, 6)` → `YYYYMMDD`
