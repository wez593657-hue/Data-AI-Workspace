## 二、业务概述

从 ODS 层 FMS 理财系统抽取数据，分代销（T1/TD）和自营（T5）两段加工，生成 DWD 层理财账户信息表。

v2.0.0 核心变更：TRUNCATE+INSERT全量覆盖 → DELETE+INSERT保留到期数据。

## 四、v2.0.0 数据流架构

```
步骤1: 参数校验 + TMP表清空
  V_SYSDAT IS NULL OR LENGTH(V_SYSDAT) != 8 → OUTCDE=-1, RETURN
  DELETE FROM TMP_DWD_ACCT_FIN_ACTIVE
  → COMMIT + SYS_PRC_STEP_LOGS

步骤2: 构建活跃快照 → TMP_DWD_ACCT_FIN_ACTIVE
  2.1 代销: FMS_TD_CUST_VOL → SELECT 20列
  UNION ALL
  2.2 自营: FMS_T5_CUST_VOL → SELECT 20列
  合并写入TMP表，字段对齐DWD_ACCT_FIN
  → COMMIT + SYS_PRC_STEP_LOGS

步骤3: DELETE + INSERT（同一事务，一个COMMIT）
  3a. DELETE FROM DWD_ACCT_FIN WHERE (CUST_ID, ACCT_ID, PRDKT_ID) IN (SELECT ... FROM TMP_ACTIVE)
  3b. INSERT INTO DWD_ACCT_FIN SELECT * FROM TMP_DWD_ACCT_FIN_ACTIVE
  → COMMIT + SYS_PRC_STEP_LOGS

步骤4: 到期标记（独立事务）
  UPDATE DWD_ACCT_FIN
  SET FIN_AMT = 0, ACCT_STATE = '已到期'
  WHERE (CUST_ID, ACCT_ID, PRDKT_ID) NOT IN (SELECT ... FROM TMP_ACTIVE)
    AND FIN_AMT > 0
  → COMMIT + SYS_PRC_STEP_LOGS
```

## 五、关键计算规则

### 5.1 理财余额（FIN_AMT）

```
FIN_AMT = ROUND(NVL(pn.NAV, 0) * NVL(cv.TOTAL_VOL, 0), 2)
```
v2.0.0: 增加ROUND保留2位小数

### 5.2 收益率（RATE_INTRI）

| 段落 | 来源 | v2.0.0 |
|------|------|--------|
| 2.1 代销 | pn.TONOWCLIENTRATIO（成立以来参考年化收益率） | ROUND(NVL(..., 0), 2) |
| 2.2 自营 | pn.SEVEN_DAYS_INCOME（7日年化收益率） | ROUND(NVL(..., 0), 2) |

v2.0.0: 移除TO_CHAR隐式转换，直接ROUND(NVL(...), 2)写入NUMBER

### 5.3 产品大类（PRDKT_CATE_BIG）

| 类型 | 判定条件 | 编码 |
|------|----------|------|
| 代销-开放 | pi.PROD_TYPE IN ('2','3') | '1' |
| 代销-封闭 | 其他 | '2' |
| 自营-开放 | pi.PERIOD_TYPE = '0' | '3' |
| 自营-封闭 | pi.PERIOD_TYPE != '0' | '4' |

### 5.4 法人行号（PERSN_LEGAL_BK_CODE）

| 条件 | 值 |
|------|-----|
| 2.1 ctl.TRANS_ORGNO LIKE '15%' / 2.2 ctl.SUB_BRANCH_CODE LIKE '15%' | '1500' |
| LIKE '12%' | '1200' |
| LIKE '18%' | '1800' |
| 其他/无交易记录 | '9999' |

### 5.5 归属机构（OPRT_ORG）

| 段落 | 来源 |
|------|------|
| 2.1 代销 | ctl.TRANS_ORGNO（无交易记录时为NULL） |
| 2.2 自营 | ci.SUB_BRANCH_CODE |

### 5.6 过滤条件

- `NVL(cv.TOTAL_VOL, 0) <> 0` — 份额为0的不入库
- `SUBSTR(ci.HOST_CUST_NO, 1, 1) = '1'` — 仅个人客户
- v2.0.0: 移除冗余条件 `NVL(cv.TOTAL_AMT, 0) > 0`

### 5.7 到期标记规则（v2.0.0新增）

当 DWD_ACCT_FIN 中某条记录的三键(CUST_ID, ACCT_ID, PRDKT_ID)不在 TMP_ACTIVE 中时：
- FIN_AMT = 0
- ACCT_STATE = '已到期'

此标记确保下游模块（到期承接、睡眠户唤醒）能正确识别到期客户。

### 5.8 事务原子性（v2.0.0新增）

- 步骤2 COMMIT：TMP快照独立持久化
- 步骤3（DELETE+INSERT）在同一事务中：要么都执行，要么都回滚
- 步骤4（到期标记）独立事务：失败不影响活跃数据的写入结果
- 异常处理：任一步骤失败 → ROLLBACK → 日志记录 → RAISE

## 六、FMS_TD_CUST_VOL到期机制

FMS_TD_CUST_VOL是实时快照表：
- 无PRIMARY KEY、无时间分区
- 客户赎回或产品到期 → TOTAL_VOL归零 → 行物理删除
- v1.0.1 TRUNCATE方案：到期数据永久丢失
- v2.0.0 DELETE+INSERT方案：不在TMP中则保留并标记到期
