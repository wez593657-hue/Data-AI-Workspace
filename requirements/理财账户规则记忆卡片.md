## 二、业务概述

从 ODS 层 FMS 理财系统抽取数据，分代销（T1/TD）和自营（T5）两段加工，生成 DWD 层理财账户信息表。

---

## 三、数据来源

### 3.1 代销理财（2.1）

| 来源表 | 别名 | 说明 |
|--------|------|------|
| FMS_TD_CUST_VOL | cv | 理财客户份额表 |
| FMS_T1_CUST_FNC_ACCT | fa | 客户理财交易账号表 |
| FMS_T1_CUST_INFO | ci | 客户信息表 |
| FMS_TD_CUST_TRANS_REQ_LOG | ctl | 客户交易请求日志（LEFT JOIN，过滤认购/申购成功） |
| FMS_TD_PROD_INFO | pi | 理财产品信息表 |
| FMS_TD_PROD_NAV | pn | 理财产品行情表（取最新净值 RN=1） |

### 3.2 自营理财（2.2）

| 来源表 | 别名 | 说明 |
|--------|------|------|
| FMS_T5_CUST_VOL | cv | 客户份额汇总表 |
| FMS_T1_CUST_FNC_ACCT | fa | 客户理财交易账号表 |
| FMS_T5_CUST_TRANS_LOG | ctl | 客户交易日志（LEFT JOIN，过滤认购/申购成功） |

| FMS_T5_PROD_INFO | pi | 产品信息表（取最新 RN=1） |

## 四、关键计算规则

### 4.1 理财余额（FIN_AMT）

```
FIN_AMT = NVL(pn.NAV, 0) × NVL(cv.TOTAL_VOL, 0)
```

### 4.2 产品大类（PRDKT_CATE_BIG）

| 类型 | 判定条件 | 编码 |
|------|----------|------|
| 代销-开放 | pi.PROD_TYPE IN ('2','3') | '1' |
| 代销-封闭 | 其他 | '2' |
| 自营-开放 | pi.PERIOD_TYPE = '0' | '3' |
| 自营-封闭 | pi.PERIOD_TYPE != '0' | '4' |

注：到期承接等下游模块按上述编码判定开放式产品（值 1 或 3），2026-08-01 已确认。

### 4.3 法人行号（PERSN_LEGAL_BK_CODE）

从交易日志（ctl）的机构号推导：

| 条件 | 值 |
|------|-----|
| 2.1 ctl.TRANS_ORGNO LIKE '15%' | '1500' |
| 2.1 ctl.TRANS_ORGNO LIKE '12%' | '1200' |
| 2.1 ctl.TRANS_ORGNO LIKE '18%' | '1800' |
| 2.2 ctl.SUB_BRANCH_CODE LIKE '15%' | '1500' |
| 2.2 ctl.SUB_BRANCH_CODE LIKE '12%' | '1200' |
| 2.2 ctl.SUB_BRANCH_CODE LIKE '18%' | '1800' |
| 其他/无交易记录 | '9999' |

### 4.4 归属机构（OPRT_ORG）

| 段落 | 来源 |
|------|------|
| 2.1 代销 | ctl.TRANS_ORGNO（无交易记录时为NULL） |
| 2.2 自营 | ci.SUB_BRANCH_CODE |

### 4.5 过滤条件

- `NVL(cv.TOTAL_VOL, 0) <> 0` — 份额为0的不入库
- `SUBSTR(ci.HOST_CUST_NO, 1, 1) = '1'` — 仅个人客户

### 4.6 最新净值/产品信息去重

- 代销（TD）：按 (TANO, PROD_CODE, SHARE_CLASS) 分区，NAV_DATE DESC 取最新
- 自营（T5）：按 PROD_CODE 分区，UPDATE_PROD_DATE/TIME/NAV_DATE DESC 取最新
