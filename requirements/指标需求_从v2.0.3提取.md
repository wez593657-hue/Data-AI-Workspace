## 一、指标管理功能

### 1.1 指标管理页面

| 功能点 | 说明 |
|--------|------|
| 页面入口 | 经营管理 → 指标管理 |
| 列表展示 | 指标名称、指标分类、状态 |
| 筛选条件 | 指标名称、指标分类、状态 |
| 状态管理 | 支持"启用"/"停用"切换 |
| 详情查看 | 点击指标名称弹出详情：基础信息、业务口径、技术口径 |
| 数据来源 | 可能来源于数据平台、其他上游系统或CRM本身加工 |

### 1.2 指标管理规则

| # | 规则 |
|---|------|
| 1 | 指标详情至少包含业务口径与技术口径两类信息 |
| 2 | 指标状态支持"启用"和"停用"两种管理状态 |
| 3 | 前端以展示为主，不擅自变更未确认的指标计算口径 |
| 4 | 指标列表数据通过后端数据初始化，前端不提供新增、编辑和删除功能 |
| 5 | "停用"的指标，目标任务管理等其它功能无法引用和查询，只能查询和引用"启用"的指标 |
| 6 | 指标列表默认按照创建时间倒序排序 |

### 1.3 权限

| 角色 | 权限 |
|------|------|
| 总行管理用户 | 可查看全部权限范围内指标数据 |
| 分行管理用户 | 可查看本分行权限范围内指标数据 |
| 其他用户 | 无权查看指标管理菜单 |

## 五、营销活动指标关联规则

### 5.1 活动创建流程

```
设置基础信息 → 选择客群 → 分配营销人 → 选择指标 → 完成
```

### 5.2 指标选择规则

| 活动类型 | 是否需选指标 | 说明 |
|----------|-------------|------|
| 综合方案 | 是 | 需选择活动关联的指标 |
| 价值提升 | 是 | 需选择活动关联的指标 |
| 客户维系 | 否 | 不选择指标，直接跳过指标选择步骤 |

### 5.3 指标选择页面

| 功能点 | 说明 |
|--------|------|
| 指标展示 | 页面展示指标名称、指标口径 |

| 查询功能 | 支持按名称过滤树形指标列表 |
| 指标分类 | 客户、AUM、存款、理财、保险、贷款、银行卡、中收 |

### 5.4 统计时间规则

- 营销活动关联的指标数据仅统计**活动开始日期**至**统计截至日期**的数据
- 统计截止时间默认联动反显结束时间，支持用户修改与调整

### 5.5 指标趋势展示（活动详情）

| 切片器 | "日"/"月"/"季"，默认"日" |

## 六、目标任务指标关联规则

### 6.1 任务创建流程

```
设置基础信息 → 选择考核指标 → 选择考核对象 → 指标分解明细
```

### 6.2 指标选择规则

| 规则 | 说明 |
|------|------|
| 指标范围 | 回显所属部门、对应考核对象类型下的全部指标 |
| 选择方式 | 指标可多选 |
| 分类展示 | 需按指标分类展示指标（客户、AUM、存款、理财、保险、贷款、银行卡、中收） |
| 校验 | 所有字段均为必输项 |

### 6.3 考核对象选择

| 考核对象类型 | 说明 |
|-------------|------|
| 机构 | 用户可按机构树选择辖下机构，可多选，可跨机构层级选择 |
| 客户经理 | 用户可按机构树选择辖下客户经理，可多选，可跨机构层级选择 |

### 6.4 指标分解明细

| 功能 | 说明 |
|------|------|
| 列表头 | 考核指标（回显第二步中选择的指标） |
| 行表头 | 考核对象（回显第三步中选择的考核对象） |
| 交叉单元格 | 输入框，必输，格式为整数，作为某考核对象的某考核指标的指标值 |
| 汇总行 | 最后一行将各考核对象的指标值相加 |

### 6.5 任务状态流转

```
待提交 → 审核中 → 审批未通过（驳回） / 未开始 → 进行中 → 已结束
```

- 上级下发的目标任务：待分解 → 已分解待提交 → 审核中 → 审批未通过/未开始/进行中/已结束
- 下发对象类型：机构（考核对象为机构但非当前机构）、本部（考核对象为当前机构）、个人（考核对象为个人用户）

### 6.6 任务分解

| 规则 | 说明 |
|------|------|
| 分解对象 | 机构或客户经理，可跨机构层级选择 |
| 考核指标 | 回显上级下发任务时的考核指标 |
| 指标值 | 分解时由操作人填写各考核对象的指标目标值 |

### 6.7 进度跟踪

| 模块 | 展示内容 |
|------|----------|
| 机构目标任务 | 横向柱状图展示考核指标的目标值、完成值、完成率，支持下钻 |
| 我的目标任务（客户经理） | 竖向柱状图展示考核指标的目标值、完成值、完成率，不支持下钻 |

### 6.8 权限

| 角色 | 目标任务管理 | 我的目标任务 |
|------|-------------|-------------|
| 总行业务岗 | 有（可新建/编辑/删除/分解/提交审核） | 无 |
| 分行业务岗 | 有 | 无 |
| 支行业务岗 | 有 | 无 |
| 网点负责人 | 有 | 无 |
| 客户经理 | 无 | 有（仅查看） |

## 十、业务规则更新（v1.1, 2026-07-30）  ← 【新增】

基于用户确认的业务规则，对指标处理逻辑进行以下调整：

### 10.1 规则#1: 目标任务客户范围界定

| 接收对象(RSV_OBJ) | 指标计算范围 | 说明 |
|-------------------|-------------|------|
| 机构(RSV_OBJ=0) | 覆盖该机构下属的**全部客户群体** | 通过 DWD_SYS_ORG 递归 SUP_ORG_ID 获取所有下级机构，汇总所有客户（不限于管户经理名下客户） |
| 理财经理(RSV_OBJ=1) | 限定为该理财经理**名下管理的全部客户** | 通过 DWD_CUST_MAN (MNG_TYP=1, MNGR_POST_ID=POST_ID) 获取该经理管户客户 |

> 影响范围: 目标任务(STATIS_CALIB='目标任务') 路径B的客户范围定义

### 10.2 规则#2: 营销活动关联指标范围

| 原规则 | 新规则 |
|--------|--------|
| 一个 MKT_ACT_ID → 产出全部28个指标 | 按 DWD_MKT_ACT_TARGT 中 MKT_ACT_ID 对应的 INDX_ID 确定具体的指标范围 |

**数据链路**: DWD_MKT_ACT_INFO → DWD_MKT_ACT_TARGT (MKT_ACT_ID → INDX_ID) → 按INDX_ID过滤指标计算

**活动类型过滤**: ACT_TYP='客户维系'不关联指标，不产出指标数据；仅 '综合方案'/'价值提升' 产出指标

> 影响范围: 营销活动(STATIS_CALIB='营销活动') 路径A的指标范围定义
