## 二、指标口径差异

### 2.1 0065 代销业务收入 — 口径不一致

| 来源 | 口径 |
|------|------|
| v2.0.3 Table 181 #21 | 保险代销 + 贵金属代销 + 理财代销 |
| 记忆卡片 | 保险代销 + 理财代销 (TODO: 贵金属缺失) |

**结论**: 记忆卡片需要更新，增加贵金属代销收入。

### 2.2 v2.0.3独有的4个指标（无INDX编码）

| 序号 | 指标名称 | v2.0.3分类 | 业务口径 | 记忆卡片状态 |
|------|----------|-----------|----------|-------------|
| 20 | 新客交叉销售 | 客户 | 新客同时持有手机银行(正常)+储蓄存款(≥100元)+理财/贷款任二 | 完全缺失 |
| 26 | 二维码收款个人活跃商户AUM留存率 | AUM | 年日均AUM/年累计交易量(≥500元商户) | 完全缺失 |
| 27 | 新增客户数 | 客户 | 考核期内新增客户号数量 | 完全缺失 |
| 28 | 借记卡新开净增量 | 银行卡 | 一类户二类户开卡量(实体卡) | 完全缺失 |

**结论**: 这4个指标在v2.0.3文档中有定义但无INDX编码，记忆卡片中完全缺失。需确认是否需要纳入本次开发。

## 三、业务规则差异

### 3.1 营销活动指标范围（关键差异）

| 来源 | 规则描述 |
|------|----------|
| 记忆卡片 路径A | 一个 MKT_ACT_ID → 产出**全部28个指标** |
| v2.0.3 文档 | 营销活动创建时**手动选择关联指标**，不同活动类型可选不同指标 |
| **用户新规则#2** | 营销活动不再关联全部指标，按 DWD_MKT_ACT_TARGT 中 MKT_ACT_ID 对应的 INDX_ID 确定指标范围 |

**结论**: 记忆卡片路径A需要更新为按 DWD_MKT_ACT_TARGT 联表获取指标范围，而非产出全部28个指标。

### 3.2 目标任务客户范围（关键差异）

| 来源 | 规则描述 |
|------|----------|
| 记忆卡片 路径B | 机构下所有理财经理名下客户 |
| v2.0.3 文档 | 考核对象可选机构或客户经理 |
| **用户新规则#1** | RSV_OBJ=机构 → 覆盖机构下属全部客户；RSV_OBJ=理财经理 → 限定为该经理名下客户 |

**结论**: 记忆卡片路径B需要区分两种接收对象类型，分别定义客户范围。

### 3.3 活动类型与指标关联

| v2.0.3规则 | 影响 |
|-----------|------|
| 综合方案/价值提升 → 需选择指标 | 记忆卡片未区分活动类型 |
| 客户维系 → 不选择指标 | 记忆卡片未提及此情况 |

**结论**: 记忆卡片需增加活动类型判断逻辑。

## 四、数据细节差异

### 4.1 储蓄存款组成

| 来源 | 组成 |
|------|------|
| v2.0.3 Table 48 | 活期存款 + 定期存款 + 个人通知存款 |
| 记忆卡片 | DEPO_CURNT_DEPO_BAL + FIXD_DEPO_BAL + LEHUI_BAL + LARGEDP_BAL + 通知存款 |

记忆卡片的组成更详细（包含乐惠存和大额存单），v2.0.3文档仅分类到定期层面。以记忆卡片的DWS层明细为准。

### 4.2 个人贷款范围

| 来源 | 范围 |
|------|------|
| v2.0.3 Table 181 #17 | 零售银行部管理的所有贷款，**不包含**普惠贷款、微粒贷和美团联合贷款 |
| 记忆卡片 | 仅标注 DWS_CUST_ASSE_LIAB LOAN_BAL |

**结论**: 记忆卡片需补充贷款排除范围。

### 4.3 0069 指标名称差异

| 来源 | 名称 |
|------|------|
| v2.0.3 Table 181 | 二维码收款个人活跃商户结算存款留存率 |
| 指标.xlsx | 二维码收款个人活跃商户结算存款留存率 |
| 记忆卡片 | 二维码存款留存率（简化名称） |

差异不涉及口径，仅名称简化。
