## 二、两条数据路径

### 路径A: 营销活动 (STATIS_CALIB='营销活动')

```
DWD_MKT_ACT_INFO (MKT_ACT_ID, ACT_TYP, ACT_BGN_DATE, STATIS_STOP_DATE)
  → DWD_MKT_ACT_ORG_REL → PRTSPT_ORG
  → DWD_MKT_TSK_INFO (MKT_ACT_ID, CUST_ID, MKT_PERSN, MKT_PERSN_ORG)
  → DWD_MKT_ACT_TARGT (MKT_ACT_ID, INDX_ID)  ← 【v1.1新增】活动-指标关联

活动类型过滤: 仅 ACT_TYP IN ('综合方案','价值提升') 才关联指标，ACT_TYP='客户维系' 不产出指标数据
客户范围: 仅 DWD_MKT_TSK_INFO 中的客户
指标范围: 按 DWD_MKT_ACT_TARGT 中 MKT_ACT_ID 对应的 INDX_ID 确定，**不再产出全部28个指标**  ← 【v1.1规则#2】
STATIS_DIM = MKT_ACT_ID
跑批: [ACT_BGN_DATE, STATIS_STOP_DATE] 每天
```

### 路径B: 目标任务 (STATIS_CALIB='目标任务')

```
DWD_MKT_INDX_TSK (TSK_ID, MKT_ACT_ID→关联Excel, RSV_OBJ, RSV_OBJ_ID, TSK_BGN_DATE, CREAT_ORG)
  → 【v1.1规则#1】按RSV_OBJ区分客户范围:
     RSV_OBJ='机构'(0): 该机构下属全部客户(递归SUP_ORG_ID获取全量客户，不限于管户经理名下)
     RSV_OBJ='理财经理'(1): 仅该理财经理名下客户(DWD_CUST_MAN, MNG_TYP=1)
  → DWD_CUST_MAN → 客户

一条 DWD_MKT_INDX_TSK → 产出对应的那一个指标
STATIS_DIM = TSK_ID
跑批: [TSK_BGN_DATE, STATIS_STOP_DATE] 每天
```

### 关联关系

```
MKT_PERSN = POST_ID AND MKT_PERSN_ORG = ORG_ID (DWD_SYS_POST)
理财经理→客户: DWD_CUST_MAN (MNG_TYP=1, MNGR_POST_ID=POST_ID)
机构层级: DWD_SYS_ORG (ORG_ID→SUP_ORG_ID 递归)
机构→理财经理: DWD_SYS_POST (ORG_ID, JOB_CLS='C', POST_STATE=有效)
活动→指标: DWD_MKT_ACT_TARGT (MKT_ACT_ID → INDX_ID)  ← 【v1.1新增】
```

## 三、机构汇总规则

```
网点→支行→分行→总行(递归SUP_ORG_ID)
每层DATA_BLNG=层级汇总值(包含所有下级+机构内客户经理)
各机构PERSN_LEGAL_BK_CODE独立
```

### DATA_BLNG数据归属产出:
- 营销活动: PRTSPT_ORG(汇总行) + MKT_PERSN(理财经理行)
- 目标任务RSV_OBJ=机构(0): 
  - **机构行**: 该机构下属全部客户汇总（不限于管户）  ← 【v1.1规则#1细化】
  - **理财经理行**: 该机构下每位理财经理名下客户分别产出  ← 【v1.1新增】
- 目标任务RSV_OBJ=理财经理(1): 下发机构CREAT_ORG + RSV_OBJ_ID(接收对象理财经理)，分别产出

## 八、业务规则版本对照  ← 【v1.1新增】

| 规则 | v1.0 | v1.1 | 变更原因 |
|------|------|------|----------|
| 营销活动指标范围 | 一个活动产出全部28个指标 | 按DWD_MKT_ACT_TARGT过滤，仅产出活动关联的指标 | 用户规则#2: 营销活动不再关联全部指标 |
| 营销活动类型 | 不区分 | ACT_TYP='客户维系'不产出指标数据 | v2.0.3文档: 客户维系无需选择指标 |
| 目标任务-机构客户范围 | 机构下理财经理名下客户 | 机构下属**全部客户**(不限于管户) | 用户规则#1: 机构→全部客户 |
| 目标任务-经理客户范围 | 未区分 | 仅该理财经理名下客户 | 用户规则#1: 理财经理→名下客户 |
| 0065代销业务收入 | 保险+理财(缺贵金属) | 保险+贵金属+理财 | v2.0.3 Table 181 #21 |
| 0062贷款范围 | 无限制 | 排除普惠/微粒贷/美团联合贷款 | v2.0.3 Table 181 #17 |
| DWD_MKT_ACT_TARGT | 无 | 新增活动-指标关联表 | 用户规则#2 |
