## 二、两条数据路径

### 路径A: 营销活动 (STATIS_CALIB='营销活动')

```
DWD_MKT_ACT_INFO (MKT_ACT_ID, ACT_TYP, ACT_BGN_DATE, STATIS_STOP_DATE)
  → DWD_MKT_ACT_ORG_REL → PRTSPT_ORG
  → DWD_MKT_TSK_INFO (MKT_ACT_ID, CUST_ID, MKT_PERSN, MKT_PERSN_ORG)  ← 【v1.3】机构取MKT_PERSN_ORG
  → DWD_MKT_ACT_TARGT (MKT_ACT_ID, INDX_ID)

活动类型过滤: 仅 ACT_TYP IN ('综合方案','价值提升') 才关联指标，ACT_TYP='客户维系' 不产出指标数据
客户范围: 仅 DWD_MKT_TSK_INFO 中的客户
指标范围: 按 DWD_MKT_ACT_TARGT 中 MKT_ACT_ID 对应的 INDX_ID 确定
STATIS_DIM = MKT_ACT_ID
跑批: [ACT_BGN_DATE, STATIS_STOP_DATE] 每天

【v1.3机构展开方式】
机构行: 从 DWD_MKT_TSK_INFO.MKT_PERSN_ORG 取叶子机构 → DWD_SYS_ORG 递归SUP_ORG_ID向上汇总
经理行: DWD_MKT_TSK_INFO.MKT_PERSN → DWD_SYS_POST.POST_ID → 经理所在机构(ORG_ID)
产出: 每个叶子机构+每个客户经理行各一条 => DATA_BLNG=机构编号/经理编号
```

### 路径B: 目标任务 (STATIS_CALIB='目标任务')

```
DWD_MKT_INDX_TSK (TSK_ID, MKT_ACT_ID→关联Excel, RSV_OBJ, RSV_OBJ_ID, TSK_BGN_DATE, CREAT_ORG)
  → 【v1.3路径B客户获取规则】按RSV_OBJ区分:
     RSV_OBJ='机构'(0): RSV_OBJ_ID = DWD_SYS_ORG.ORG_ID（接收机构）
        → 从 DWS_CUST_LVL_INFO（全量客户等级表）中取 ORG_ID = RSV_OBJ_ID 的所有客户
        → 不再通过 DWD_CUST_MAN 管户关系获取  ← 【v1.3变更: 机构直接从客户等级表取客户，不通过管户】
     RSV_OBJ='理财经理'(1): RSV_OBJ_ID = 接收经理编号
        → DWD_CUST_MAN (MNG_TYP=1, MNGR_POST_ID=RSV_OBJ_ID) → 该经理名下客户

一条 DWD_MKT_INDX_TSK → 产出对应的那一个指标
STATIS_DIM = TSK_ID
跑批: [TSK_BGN_DATE, STATIS_STOP_DATE] 每天
```

### 关联关系

```
MKT_PERSN = POST_ID AND MKT_PERSN_ORG = ORG_ID (DWD_SYS_POST)  ← 【v1.3】路径A机构从MKT_PERSN_ORG取
理财经理→客户: DWD_CUST_MAN (MNG_TYP=1, MNGR_POST_ID=POST_ID)
机构层级: DWD_SYS_ORG (ORG_ID→SUP_ORG_ID 递归)
路径A机构→理财经理: DWD_SYS_POST (ORG_ID, JOB_CLS='C', POST_STATE=有效)
路径B 机构→客户: DWS_CUST_LVL_INFO.ORG_ID（全量客户，不通过管户）  ← 【v1.3新增】
活动→指标: DWD_MKT_ACT_TARGT (MKT_ACT_ID → INDX_ID)
```

## 三、机构汇总规则 + 数据归属 (DATA_BLNG)

```
网点→支行→分行→总行(递归SUP_ORG_ID)
每层DATA_BLNG=层级汇总值(包含所有下级+机构内客户经理)
各机构PERSN_LEGAL_BK_CODE独立
```

### DATA_BLNG数据归属产出:
- 营销活动: 从 MKT_PERSN_ORG 叶子机构递归向上产出机构行 + MKT_PERSN客户经理行  ← 【v1.3】
- 目标任务RSV_OBJ=机构(0): 
  - **机构行**: DWS_CUST_LVL_INFO.ORG_ID中该机构的所有客户汇总  ← 【v1.3: 不通过管户，直接从客户等级表取】
  - 由机构行递归SUP_ORG_ID向上汇总上级机构
- 目标任务RSV_OBJ=理财经理(1): 下发机构CREAT_ORG + RSV_OBJ_ID(接收对象理财经理)，分别产出

### 为什么客户经理维度会产出机构行？

路径A中，MKT_PERSN_ORG是每位客户经理所在的**叶子机构**。需要同时产出:
1. **客户经理行** (DATA_BLNG=MKT_PERSN): 该经理名下客户指标汇总 — 用于考核个人
2. **机构行** (DATA_BLNG=MKT_PERSN_ORG向上递归): 叶子机构→支行→分行各层汇总 — 用于考核机构整体
   
这是标准的"个体+团体"双纬度考核模式: 上级既需要看每位客户经理的单人业绩, 也需要看一个网点/支行的整体经营情况。
