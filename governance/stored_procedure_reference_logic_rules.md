# 存储过程参考逻辑规则

## 适用范围

适用于所有新增或修改的 CRM 存储过程、ETL SQL 和指标统计逻辑。

## 强制要求

开发开始前必须先检索：

1. `data_assets/reference_logic/` 中与当前需求相关的参考逻辑文件；
2. `data_assets/stored_procedure/` 中已开发的相似存储过程；
3. 当前需求、Mapping、目标 DDL、源表 DDL 和需求记忆卡片。

检索重点至少包括：

- 源表与目标表；
- JOIN 条件及法人行号条件；
- WHERE 过滤条件；
- 跑批日期及历史快照日期；
- 去重、客户范围冻结和指标粒度；
- GROUP BY、机构递归和异常处理。

## 复用与差异记录

- 已有逻辑满足当前口径时，应优先复用并保持命名和处理方式一致。
- 当前口径与参考逻辑不一致时，以当前已确认需求为准，并记录差异、原因和影响范围。
- 不能由参考逻辑推断出的字段、过滤条件或业务规则不得自行补齐。
- 参考逻辑不等于运行时验证证据，仍需完成静态校验、编译和必要的样例回放。

## MTS_OBJECT.sql 引用规则

`data_assets/reference_logic/MTS_OBJECT.sql` 可作为逻辑口径和筛选条件的参考来源。每处实际复用必须在存储过程 SQL 注释、需求记忆卡片或变更说明中单独记录：

- 来源文件：`data_assets/reference_logic/MTS_OBJECT.sql`；
- MTS 对象和字段：`MTS.<TABLE_NAME>.<COLUMN_NAME>`；
- 具体复用的 JOIN、WHERE、状态、日期或去重条件；
- 文件中的定位依据：行号或稳定检索关键字。

禁止只标注“MTS参考”而未明确对象、字段和条件。引用不能替代当前需求确认；MTS 文件中无法证明的业务规则不得自行推断。
